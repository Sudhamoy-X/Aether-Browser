# Aether Browser v3.0.0

A new release of Aether Browser for Android.

## Release highlights

- Modern, clean browsing experience
- Tab management
- Private browsing
- Ad and pop-up blocking
- Video Assistant
- Desktop mode
- Data Saver
- Download Manager
- Night Mode
- Find in Page
- Custom browsing settings

## Installation

1. Download `app-release.apk` from the Assets section below.
2. Open the APK on your Android device.
3. Allow installation from this source if Android requests permission.
4. Complete installation.
